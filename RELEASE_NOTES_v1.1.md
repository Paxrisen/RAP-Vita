# RAP-Vita v1.1 – Two players on one Vita! 🎮🎮

## What's new
- **Twin Mode (landscape):** two ships on one screen. Red uses the left side (left stick, L, D-pad), blue the right side (right stick, R/Cross/Square, Circle, Triangle). Can also be played solo by controlling both ships.
- **Co-op portrait (split screen):** the screen is split in two halves, each rotated towards the player at that end of the Vita. Choose **L** (red sits left) or **R** (red sits right).
- Shields, weapons, ammo and money are shared – player 1 (red) leads in hangar and shop.
- Red and blue triangles mark the two ships.
- Two-player options appear in the SELECT menu once a game is loaded (hangar).
- Fix: the SELECT menu no longer stays on screen in the main menu after closing it.

## Installation / update
Install `Rap-Vita_v1.1.vpk` with VitaShell (your saves and settings are kept). Game data: `FILE0000.GLB`–`FILE0004.GLB` from your own Raptor copy in `ux0:data/Raptor/`.
