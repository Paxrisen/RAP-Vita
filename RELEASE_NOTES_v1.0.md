# RAP-Vita v1.0

First release of RAP-Vita – a native PS Vita port of *Raptor: Call of the Shadows*, based on [skynettx/raptor](https://github.com/skynettx/raptor) (GPL-2.0).

**No game data included** – copy `FILE0000.GLB`–`FILE0004.GLB` from your own Raptor copy (e.g. GOG) to `ux0:data/Raptor/`.

### Highlights
- Native, original game speed
- Pointer + touch controls in menus, on-screen keyboard for pilot names
- SELECT menu (English/German): settings, per-orientation button mapping, screenshots
- Portrait mode (R/L), optionally only during levels
- Touch steering in game, D-pad sensitivity, 4:3 / wide / fullscreen

### Files
- `Rap-Vita_v1.0.vpk` – install with VitaShell
- `RAP-Vita-v1.0-src.zip` – complete source code (GPL-2.0)
